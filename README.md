# Persona Tags

SillyTavern 人设管理增强插件。

人设一多就乱，分不清谁是谁。这个插件让你给人设打标签、按标签筛选、批量管理、拖拽排序，把乱糟糟的人设列表理清楚。

本仓库为个人维护分支，基于原版 v2.0.0 调整，自用为主。

## 功能

### 标签系统
- 给人设打标签，逗号分隔一次加多个
- 按标签筛选人设，支持正向（只看选中的）和反向（藏起选中的）
- 筛选面板内置搜索框，打字即时过滤标签
- 标签按使用频率自动排序（人数多的在前）
- 「当前角色」模式下，筛选面板只显示该角色人设实际用到的标签
- 筛选面板里长按标签可以拖动排序（同频率时手动顺序生效）
- 当前角色卡绑定的人设的标签会微微发亮
- 人设卡片上直接显示标签
- 创建人设时可以一起填标签

### 角色归属
- 人设卡片上叠小头像，一眼看出绑定了哪些角色卡（群组显示为图标），悬停看名字
- 视图栏「按角色筛选」下拉框：选中任意角色卡/群组，只看绑给它的人设

### 批量管理
- 点「批量」按钮进入批量模式，卡片出现复选框
- 全选 / 取消全选
- 批量置顶 / 置底（调整排序）
- 批量打标签、批量删标签、批量删除

### 排序
- 长按人设卡片拖拽排序（手机也能用）
- 右栏输入位置数字精确跳转
- 每张卡片显示当前排序位号
- 「全部人设」和每个角色卡的绑定人设各有独立排序，互不干扰

### 视图
- 「当前角色」模式：只看当前角色卡绑定的人设
- 「全部人设」模式：看所有人设
- 刷新按钮手动刷新列表
- 列表/网格两种视图都支持

### 其他
- 复制人设时自动带上标签，并绑定到当前角色（未选中角色则不绑定）
- 多个人设绑同一角色卡时，选择弹窗能看到头像、名字、标签
- ST 原生的英文弹窗（创建、重命名、删除等）全部汉化

## 安装

把 `persona-tags` 文件夹放到：

```
SillyTavern/public/scripts/extensions/third-party/persona-tags/
```

刷新页面就能用。

## 数据

标签和排序数据存在 SillyTavern 的 `extension_settings` 里，不碰原有数据。删掉插件文件夹就恢复原样，数据留在设置里不会影响 ST 正常使用。
